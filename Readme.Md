# Automated Web Scraping & ETL Pipeline

## Overview
This project demonstrates a production-style web scraping pipeline that extracts
data from dynamic websites, cleans and normalizes records, and loads them into PostgreSQL.

## Tech Stack
- Python
- Selenium
- BeautifulSoup
- Pandas
- PostgreSQL

## Features
- Handles JavaScript-rendered pages
- Data normalization and deduplication
- Database-level constraints
- Modular and scalable architecture

## How to Run
1. Install dependencies
   pip install -r requirements.txt
2. Update database config
3. Run the pipeline
   python main.py
